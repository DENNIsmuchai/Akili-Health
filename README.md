# Akili Wellbeing Frontend

A responsive Next.js frontend concept for a school wellbeing hub. The interface is a frontend-only prototype: conversational replies, journal saves, mood check-ins, and staff metrics are sample interactions. Spotify playback, authentication, secure storage, crisis routing, AI services, and school-specific support contacts need backend or deployment configuration.

## Run locally

1. Install Node.js 20 or newer and pnpm.
2. Run `pnpm install`.
3. Run `pnpm dev` and open the local URL printed by Next.js.

The role control in the header cycles through Student, Psychology, and Admin views. Use the urgent-help link in the sidebar to preview the support dialog.
